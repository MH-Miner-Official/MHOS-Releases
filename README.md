# MHOS

Операционная система для майнинга с управлением через [веб-кабинет](https://ru.mhminer.ru/app/). Флешка или SSD от **8 ГБ**.

| Версия | Для чего | Скачать |
|---|---|---|
| **Проверенная** | Проверена владельцем на риге | [Образ](https://github.com/MH-Miner-Official/MHOS-Releases/releases/download/2026.11.23/MHOS-2026.11.23.img.gz) · [Установка](https://github.com/MH-Miner-Official/MHOS-Releases/releases/tag/2026.11.23) |
| **Тестовая** | Настройки локальной сети и SSH; ещё проходит испытания | [Образ](https://github.com/MH-Miner-Official/MHOS-Releases/releases/download/2026.11.23.1/MHOS-2026.11.23.1.img.gz) · [Инструкция](https://github.com/MH-Miner-Official/MHOS-Releases/releases/tag/2026.11.23.1) |

Запишите образ через balenaEtcher, впишите `CODE=MHF-XXXX-XXXX` в `mhos.txt`, загрузите риг с накопителя и примените полётный лист в кабинете. Secure Boot отключите.
